# Michigan Utilities Privacy Policy

**Effective Date:** August 3, 2026

## 1. Introduction

Michigan Utilities ("the Bot") is committed to protecting the privacy of its users. This Privacy Policy explains what information is collected, how it is used, and your rights regarding that information.

## 2. Information We Collect

The Bot may collect and store the following information when required for its functionality:

* Discord Server IDs
* Discord Channel IDs
* Discord Role IDs
* Discord User IDs (only when required for bot features)
* Server configuration settings
* Moderation configuration
* Verification configuration
* Command configuration

The Bot does **not** permanently store users' message content for normal operation.

## 3. How Information Is Used

Collected information is used solely to provide the Bot's features, including but not limited to:

* Server configuration
* Moderation
* Role management
* Verification
* Logging
* Prefix command handling
* Administrative utilities

## 4. Data Sharing

Michigan Utilities does not sell, rent, or share collected information with third parties except where required by law.

## 5. AI and Machine Learning

Michigan Utilities does not use Discord data or message content to train artificial intelligence or machine learning models.

## 6. Data Retention

Configuration data is retained only as long as necessary for the Bot to function within a server. Data may be removed when the Bot is removed from a server or upon a valid deletion request.

## 7. Data Deletion

Server owners or authorized administrators may request deletion of stored data by contacting the developer through the official Michigan Utilities support server.

Upon verification of ownership or administrative authority, the requested data will be permanently deleted where applicable.

## 8. Security

Reasonable measures are taken to protect stored information from unauthorized access. However, no storage method or internet transmission is completely secure.

## 9. Changes to This Policy

This Privacy Policy may be updated periodically. Continued use of Michigan Utilities after changes constitutes acceptance of the updated policy.

## 10. Contact

For privacy-related questions or data deletion requests, please contact the developer through the official Michigan Utilities Support Server.
